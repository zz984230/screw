# UI/交互规范

## 主页面
- 仅显示一个对话框输入区，提供占位提示与提交按钮“确定”。
- 右侧历史侧边栏默认展开，支持折叠与宽度拖拽。

## 输入行为
- Enter 提交；Shift+Enter 换行；Ctrl+Enter 强制提交。
- 提交后输入禁用并显示加载，结果以流式逐步显示。
- 提供“停止生成”“继续”控制；错误弹窗与重试按钮。

## 历史侧边栏
- 以会话分组显示消息：用户靠右、模型靠左。
- 支持搜索、复制、固定、删除、导出；点击会话继续对话。
- 新提交自动创建或续接当前会话并追加消息。

## 渲染
- 支持 Markdown 与代码块复制按钮。
- 空态提示常用问题与快捷键：Esc 聚焦输入、Ctrl+K 打开命令面板（预留）。
