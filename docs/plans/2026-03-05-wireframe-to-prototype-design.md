# Wireframe to Prototype Skill 设计文档

## 概述

将手机App/小程序的框图（手绘草图、线框图、文字描述）转换为可交互的HTML界面原型。

## 需求总结

| 维度 | 需求 |
|------|------|
| 目标平台 | 微信小程序 + 手机App（iOS/Android/鸿蒙）界面原型 |
| 输入格式 | 手绘草图、线框图图片、ASCII/文字描述 |
| 输出形式 | 可交互HTML原型（静态页面，可切换） |
| 使用方式 | Claude Code Skill |
| 交互程度 | 静态展示 + 页面切换 |
| 设计风格 | 默认智能设计 + 支持自定义配置 |
| 技术栈 | Tailwind CSS |
| 工作流程 | 确认理解 → 生成 → 可迭代优化 |

## 技术方案

**方案：纯Skill方案，复用 frontend-design**

```
wireframe-to-prototype (入口 skill)
    │
    ├── 1. 分析框图（图片/文字）
    │      ↓
    ├── 2. 输出识别结果供用户确认
    │      ↓
    ├── 3. 构建 mobile-specific 设计提示
    │      ↓
    └── 4. 调用 frontend-design skill 生成原型
```

### 职责划分

| Skill | 职责 |
|-------|------|
| `wireframe-to-prototype` | 框图分析、界面结构识别、移动端规范、用户确认流程 |
| `frontend-design` | HTML/Tailwind CSS 原型生成、设计美化 |

## 详细工作流程

### Step 1：接收输入

```
用户输入：
- 图片（手绘草图 / 线框图）+ 可选文字说明
- 或纯文字/ASCII描述
```

### Step 2：分析框图

Skill 自动识别：
- **页面数量**：单页 / 多页
- **页面类型**：启动页、登录页、首页、列表页、详情页、表单页、个人中心等
- **UI元素**：导航栏、按钮、输入框、列表、卡片、图标、底部Tab等
- **布局结构**：头部、内容区、底部导航
- **目标平台**：小程序风格 / App风格（根据元素特征推断）

### Step 3：展示识别结果（供用户确认）

```
📝 识别结果：

📱 页面数量：2个
   - 页面1：登录页
   - 页面2：首页（列表）

🎯 目标平台：微信小程序风格

🧩 识别到的元素：
   - Logo区域
   - 手机号输入框
   - 验证码输入框 + 获取验证码按钮
   - 登录按钮
   - 底部Tab导航（首页、消息、我的）

🎨 设计风格：自动智能设计（可自定义）

确认生成原型？或需要修改？
```

### Step 4：用户确认/修改

用户可以：
- 确认直接生成
- 修改识别结果（如"是App风格不是小程序"）
- 添加自定义配置（颜色、字体等）

### Step 5：生成原型

调用 `frontend-design` skill，传入：
- 界面结构描述
- 移动端尺寸规范（375x667 或 390x844）
- 设计风格参数
- 交互需求（页面切换）

### Step 6：输出结果

- 生成可交互HTML文件
- 用户可继续对话优化

## 配置选项

### 自动推断的设计配置

| 配置项 | 自动推断逻辑 |
|--------|-------------|
| 主色调 | 根据行业/用途推断（如电商用橙红、金融用蓝、社交用绿） |
| 风格 | 小程序用轻量简洁、App用现代感 |
| 圆角 | 默认8-12px |
| 字号 | 遵循移动端规范 |

### 用户可自定义的配置

```
🎨 自定义配置示例：

--theme: #1890ff          # 主色调
--theme-light: #e6f7ff    # 浅色背景
--text-primary: #333      # 主文字颜色
--font-family: -apple-system  # 字体
--border-radius: 8px      # 圆角大小
--platform: wechat        # 平台风格：wechat/app
```

## 移动端规范（内置）

### 尺寸规范

```
- 设计稿宽度：375px（iPhone标准）
- 安全区域：顶部44px，底部34px
- 状态栏：20px
```

### 间距规范

```
- 页面边距：16px
- 元素间距：12px
- 列表项高度：44-56px
```

### 字号规范

```
- 大标题：20px
- 标题：16px
- 正文：14px
- 辅助文字：12px
```
