# Wireframe to Prototype

将框图转换为可交互的移动端HTML原型。

## 输入格式

支持三种输入：

1. **图片输入** - 手绘草图拍照、线框图工具导出的图片
2. **文字描述** - 用文字描述界面布局和元素
3. **ASCII框图** - 用符号绘制的简单框图

## 输出

- 可交互的HTML原型（Tailwind CSS）
- 支持页面切换
- 移动端尺寸适配（375px宽度）

---

## 工作流程

### 1. 接收输入

当用户上传图片或提供文字描述时：

**如果输入是图片：**
- 仔细观察图片内容
- 识别手绘或线框图的各个元素
- 注意标注的文字和连接线

**如果输入是文字/ASCII：**
- 解析文字描述的界面结构
- 识别ASCII符号表示的布局

### 2. 分析框图

自动识别以下信息：

**页面分析：**
- 页面数量（单页/多页）
- 页面之间的跳转关系

**页面类型识别：**
- 启动页/闪屏
- 登录页/注册页
- 首页/主页面
- 列表页
- 详情页
- 表单页
- 个人中心
- 设置页
- 搜索页
- 其他

**UI元素识别：**
- 导航栏（标题、返回按钮、操作按钮）
- 输入框（文本、密码、搜索框）
- 按钮（主要、次要、文字按钮）
- 列表（单行、多行、带图标）
- 卡片
- 底部Tab导航
- 图片区域
- 文字内容

**布局结构：**
- 头部区域
- 内容区域
- 底部区域

**平台推断：**
- 微信小程序风格（胶囊按钮、特定导航栏）
- App风格（原生导航栏、底部安全区）

### 3. 确认识别结果

使用以下格式展示识别结果，等待用户确认：

```
📝 识别结果：

📱 页面数量：[数量]个
   - 页面1：[页面类型/名称]
   - 页面2：[页面类型/名称]
   ...

🎯 目标平台：[微信小程序/App]

🧩 识别到的元素：
   - [元素1]
   - [元素2]
   ...

🎨 设计风格：自动智能设计（可自定义）
   - 主色调：[推断的颜色]
   - 风格：[简洁/商务/活泼等]

确认生成原型？或需要修改？
```

### 4. 处理用户反馈

**如果用户确认：** 进入生成阶段

**如果用户要求修改：**
- 根据用户反馈调整识别结果
- 更新页面类型、元素、平台或设计风格
- 重新展示确认信息

**如果用户提供自定义配置：**
- 记录用户指定的颜色、字体等配置
- 在生成阶段应用这些配置

支持的配置项：
- `--theme`: 主色调（如 #1890ff）
- `--theme-light`: 浅色背景
- `--text-primary`: 主文字颜色
- `--font-family`: 字体
- `--border-radius`: 圆角大小
- `--platform`: 平台风格（wechat/app）

### 5. 生成原型

**调用 frontend-design skill：**

使用 Skill tool 调用 frontend-design skill，传入以下信息：

```
请使用 frontend-design skill 生成移动端界面原型：

**目标：** [微信小程序/App] 界面原型

**页面：**
1. [页面1名称]：[元素描述]
2. [页面2名称]：[元素描述]

**设计规范：**
- 宽度：375px（iPhone标准）
- 框架：Tailwind CSS
- 风格：[设计风格描述]
- 主色调：[颜色]
- [其他自定义配置]

**交互需求：**
- 支持页面切换（底部Tab/按钮跳转）
- 静态展示为主

**参考移动端规范：**
- 页面边距：16px
- 元素间距：12px
- 列表项高度：44-56px
- 大标题：20px
- 标题：16px
- 正文：14px
- 辅助文字：12px
```

### 6. 迭代优化

生成原型后，用户可以继续对话进行优化：

**常见优化请求：**
- "把主色调改成蓝色"
- "这个按钮太小了"
- "添加一个返回按钮"
- "字体再大一点"
- "列表项增加图标"

**处理方式：**
- 直接调用 frontend-design skill 进行修改
- 或提供修改后的HTML代码

## 重要设计原则

### 1. 审美与艺术感优先
- **不要完全照搬原始框图布局** - 框图只是功能参考，不是视觉约束
- **发挥设计师的专业审美** - 用时尚、现代、有艺术感的方式重新组织布局
- **追求视觉平衡与美感** - 留白、对齐、层次、呼吸感
- **参考顶级 App 设计** - 如苹果原生应用、Notion、Linear 等

### 2. 布局设计自由
- 框图的功能模块关系可以参考，但布局方式可以自由发挥
- 可以尝试：卡片式、网格布局、分层堆叠、沉浸式等
- 优先考虑用户体验和视觉美感，而非还原草图

### 3. 时尚设计元素
- 使用当下流行的设计趋势（玻璃拟态、新拟态、极简主义等）
- 精致的动效和微交互
- 高质量的视觉层次和信息架构

## 平台设计规范（严格遵循）

### iOS App 设计规范
当用户要求生成「苹果 App」「iOS App」界面时，**必须严格遵循** iOS Human Interface Guidelines：

**尺寸与间距：**
- 设计稿宽度：390px（iPhone 14 Pro / 15）
- 状态栏高度：47px（灵动岛设备）
- 导航栏高度：44px
- 底部安全区：34px
- Tab Bar 高度：49px + 安全区
- 页面边距：16-20px
- 元素间距：8pt/16pt 网格系统

**圆角规范：**
- 小组件/按钮圆角：8-10px
- 标准卡片圆角：10-12px
- 大卡片/弹窗圆角：12-16px
- 首页小组件：22px（iOS 15+ 标准）
- 使用 `continuous` 圆角（流畅圆角）

**边框与阴影：**
- 分隔线：0.5px 高度，颜色 `#C6C6C8`（light）/`#38383A`（dark）
- 卡片边框：通常无边框，使用阴影或背景色区分
- 阴影参数：`0 2px 8px rgba(0,0,0,0.08)` 微妙阴影
- 使用 `backdrop-filter: blur(20px)` 实现 iOS 毛玻璃效果

**颜色系统：**
- 系统背景：`
- 系统背景：`#FFFFFF`（light）/`#000000`（dark）
- 分组背景：`#F2F2F7`（light）/`#1C1C1E`（dark）
- 标签栏背景：`
- 标签栏背景：`#F9F9F9`（light，90%透明度+模糊）/`#1C1C1E`（dark）
- 主色调：系统蓝 `#007AFF`
- 文字：`
- 文字：`#000000`（主标题）/`#3C3C43`（副标题）/`#8E8E93`（辅助）
- 深色模式文字：`#FFFFFF` / `#EBEBF5` / `#8E8E93`

**字体规范：**
- 字体家族：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display"`
- 大标题：34px，半粗体
- 标题1：28px，半粗体
- 标题2：22px，半粗体
- 标题3：20px，半粗体
- 正文：17px，常规
- 小字：15px / 13px / 11px

**组件规范：**
- 按钮高度：44-50px
- 列表项高度：44px（单行）/ 60-80px（多行）
- 分段控制器（Segmented Control）：圆角胶囊样式
- 搜索栏：圆角 10px，高度 36px
- 开关：iOS 标准开关样式

### 微信小程序设计规范
当用户要求生成「微信小程序」界面时，**必须严格遵循** WeUI 设计规范：

**尺寸与间距：**
- 设计稿宽度：375px（iPhone 标准）
- 状态栏高度：20-44px（根据机型）
- 导航栏高度：44px
- 胶囊按钮区：右侧预留 87px
- 底部安全区：适配 iPhone X 系列
- 页面边距：16px
- 元素间距：8px/16px/24px 网格系统

**圆角规范：**
- 按钮圆角：4-8px
- 卡片圆角：8-12px
- 弹窗圆角：12px
- 大卡片圆角：16px
- 比 iOS 更小的圆角，更方正的感觉

**边框与阴影：**
- 分隔线：0.5px，`#E5E5E5`
- 卡片通常有明显的浅色边框或分割线
- 阴影更克制，或不用阴影用边框
- 顶部/底部细线分隔是微信的特色

**颜色系统：**
- 主色：`#07C160`（微信绿）
- 主色按下：`#06AD56`
- 背景：`#F5F5F5`（灰白）
- 卡片背景：`#FFFFFF`
- 文字主色：`#000000`（100%）
- 文字次色：`#000000`（60%透明度）
- 文字辅助：`#000000`（40%透明度）
- 边框：`#E5E5E5` 或 `#000000`（10%透明度）

**字体规范：**
- 字体：`PingFang SC`, `Hiragino Sans GB`, `Microsoft YaHei`
- 导航标题：17px，常规字重
- 正文：16px
- 辅助文字：14px / 12px
- 微信字体比 iOS 略小一号

**组件规范：**
- 按钮高度：44-46px
- 列表项：60px 高度，左侧图标 + 文字 + 右侧箭头
- 输入框：48px 高度，底部边框风格
- Tab Bar：微信原生组件，不去自定义样式
- 顶部导航栏：使用微信原生导航栏，不自定义

## 注意事项

1. **始终先确认再生成** - 避免误解用户意图
2. **移动端优先** - 所有设计以375px宽度为基准
3. **简洁实用** - 原型是展示用途，不需要复杂交互
4. **复用能力** - 充分利用 frontend-design skill 的设计能力
5. **迭代友好** - 生成后支持继续优化修改
6. **审美优先** - 宁可偏离框图，也要保证设计美观
